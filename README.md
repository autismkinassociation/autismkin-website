# Autism Kin website

Public website for Autism Kin Association, served at https://autismkin.com via GitHub Pages.

- `index.html` – the whole site (English, Spanish, Chinese), Caregiver Course, accounts and admin dashboard (`/#admin`)
- `pdfs/` – downloadable family guides; `img/` – images
- `firebase/firestore.rules` – database security rules (paste into Firebase console → Firestore → Rules)
- `CNAME` – custom domain for GitHub Pages
